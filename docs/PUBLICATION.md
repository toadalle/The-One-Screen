# Public repository contents

This repository was prepared from The One Screen alpha 1.1.12. It includes source, configuration, tests, development notes, compiled mod files, and four gameplay screenshots supplied by the author.

Retail ROMs/executables, pristine retail build inputs, local emulator state, personal browser screenshots, font binaries, external mod archives, and build caches are excluded. The GameBanana form screenshots were used only as presentation references and were not uploaded.

No new license grant is inferred for inherited third-party material or game-derived assets. See PROVENANCE.md and the asset audit.
