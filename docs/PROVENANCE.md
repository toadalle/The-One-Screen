# Provenance

The user supplied Project Materials and authorized analysis and a rewrite.
Retail code and resource bases are build inputs and are not redistributed
with this project. The CCI itself is not repackaged.

Recovered z3D ABI/type headers, HID/IRRST declarations, IRRST IPC and SVC
wrappers were retained from the supplied reference project. Texture codec
and atlas-building utilities and custom PNG artwork were adapted from the
provided mod materials; this is a feature-backend rewrite, not a claim that
every declaration, codec or asset was newly authored. Exheader baseline was
supplied by the previous release and is adjusted by the new build.

Native addresses and seams are tied to the exact USA Rev 1 executable.
Downloaded Azahar loader sources were inspected only in the work directory
and are not bundled. Loader analysis reference:
https://github.com/azahar-emu/azahar/blob/86a9f9236ae42bb5a2b995dbc933d599d8ea07ac/src/core/loader/ncch.cpp

No license grant for inherited project material is inferred. Before public
distribution, retain and resolve upstream notices for the supplied headers,
platform wrappers, codecs and assets.
