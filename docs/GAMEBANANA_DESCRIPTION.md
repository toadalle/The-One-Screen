# GameBanana listing text

## Title

The One Screen

## Subtitle

A single-screen controller overhaul for Ocarina of Time 3D.

## Description

The One Screen is a comprehensive single-screen conversion for The Legend of Zelda: Ocarina of Time 3D, designed to make the game feel natural on a traditional controller and modern emulator setup.

The mod adapts the UI, controls, HUD, menus, Ocarina interface, and screen routing so touchscreen-dependent features can be used comfortably with a traditional controller.

Features include a redesigned HUD, Xbox-style contextual labels, LB/RB item functionality, correct X/Y item-slot behavior, reworked Ocarina presentation, D-pad shortcuts, Start for Pause/System, and Select for Map.

Compatibility: USA Rev 1, title ID 0004000000033500. Tested primarily with Azahar. Extract the included load folder into your Azahar user directory. A legally obtained game copy is required; no ROM, CIA, CCI, or decrypted retail executable is included.

Developed through reverse engineering, testing, iteration, and community tooling. AI-assisted development tools, including ChatGPT and Codex, were used during portions of reverse engineering and implementation.
